# Animation Basics in After Effects: Getting Started with Motion

Adobe After Effects is the industry standard for motion graphics and visual effects. This guide will introduce you to the basic principles of animation within After Effects.

## Understanding Keyframes

Keyframes are the foundation of animation in After Effects. They mark specific points where you define an object's properties, such as:

- Position
- Scale
- Rotation
- Opacity
- Effects parameters

## Basic Animation Workflow

1. **Setting Up Your Composition**

   - Create a new composition
   - Set appropriate dimensions and duration
   - Import your assets

2. **Creating Your First Animation**

   - Select your layer
   - Press 'P' for position
   - Click the stopwatch to create keyframes
   - Move the playhead
   - Change position for second keyframe

3. **Understanding the Graph Editor**
   - Access it using Shift+F3
   - Adjust velocity curves
   - Create smooth or sharp movements

## Essential Animation Principles

- Ease in and ease out
- Anticipation
- Follow-through
- Squash and stretch
- Timing and spacing

## Tips for Better Animations

- Use the Preview RAM for smooth playback
- Learn to use the Graph Editor early
- Practice the 12 principles of animation
- Start simple and build complexity
- Use null objects for better control

Remember that great animation takes time and practice. Focus on mastering these basics before moving on to more complex techniques.
