## 1. Download Odin Pro Manager

1. Go to **odinpro.com** and register a new account.
2. Open the **Download** section and download **Odin Pro Manager**.
3. Unzip the downloaded archive.
4. Run the installer file and follow the on-screen instructions.

## 2. Open the Odin Pro extension in your software

<iframe
	width="560"
	height="315"

	frameBorder="0"

	referrerPolicy="strict-origin-when-cross-origin"

1. Launch **Adobe Premiere Pro** or **Adobe After Effects**.
2. In the top menu, go to:

   - **Window → Extensions → Odin Pro** (for legacy extension menu), or
   - **Window → Odin Pro** (if Odin Pro appears directly in the Window menu).

## 3. Log in

1. In the Odin Pro panel, log in using the **email** and **password** you used to register on the website.

## 4. Install packs for your software

1. Inside Odin Pro, select the required **software**:

   - **Premiere Pro**
   - **After Effects**

2. Choose the **required version** or **pack** from the list.
3. Click **Install**.
4. Wait until the installation is complete — after that the pack is fully ready to use in your projects.
