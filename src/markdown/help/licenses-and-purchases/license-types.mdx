# License Types

Odin Pro offers several **paid license plans**:

- **Monthly plan**
- **Yearly plan**
- **Lifetime license**

All **paid plans** are available under **two license types**:

- **Regular License**
- **Commercial License**

---

## Regular License

The **Regular License** is intended for **personal use only**.

You can:

- Use Odin Pro assets in personal projects
- Create non-commercial and non-monetized content

You cannot:

- Use the assets for paid client work
- Monetize content created with Odin Pro assets

---

## Commercial License

The **Commercial License** allows usage of Odin Pro assets in **commercial projects**.

You can:

- Use assets for client work
- Monetize videos and content on platforms such as YouTube and social media
- Use assets in advertising and promotional projects

---

## Free Pack License

The **Free Pack** is available **only under the Regular License**.

This means:

- It can be used **for personal use only**
- Commercial usage is **not allowed**

---

## Redistribution Policy

Reselling, redistributing, sharing, or re-uploading Odin Pro packs or individual elements is **strictly prohibited**, regardless of license type.
